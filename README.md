## 💻 Getting Started

### 1. Run Development Server
Inside the `portfolio` folder, run:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### 2. Build for Production
To generate an optimized production build:
```bash
npm run build
```

### 3. Start Production Server
```bash
npm run start
```

## 📁 Customizing Your Content

All data is centrally managed in a single typed configuration file:
- **`src/data/portfolioData.ts`**:
  - Update your bio, email, phone number, and location
  - Add your GitHub and LinkedIn profile URLs
  - Add new projects, skills, or career milestones

### Adding Your Profile Picture or Resume PDF:
1. Place your avatar photo in `portfolio/public/avatar.jpg`
2. Place your resume PDF in `portfolio/public/resume.pdf`

## 🌐 Deployment

You can deploy this Next.js project to **Vercel**, **Netlify**, or any cloud platform:
1. Push your `portfolio` directory to a GitHub repository.
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel automatically detects Next.js and deploys your site with global edge CDN caching!
